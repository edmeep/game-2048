# game-2048  
## 项目介绍
这是一个2048游戏  
项目由三部分组成：  
- index.html: 页面结构 
- index.css: 页面样式  
- game.js: 游戏逻辑  
## 功能  
### 玩法  
- 4 * 4棋盘
- 四个方向移动  
- 相同数字方块碰撞自动合并，并累计加分  
- 每次有效移动随机生成新方块：90%概率生成2,10%概率生成4  
- 无效移动不会生成新方块  
### 计分和状态  
- 当前得分（score）: 每次合并后累积的数值  
- 最高分（best/last）: 通过localstorage保存，刷新不丢失  
- 步数（moves）: 有效移动次数  
- 胜利判定：合成2048时获得胜利，且可继续挑战更高分  
- 失败判定： 棋盘填满且没有合并方向时游戏失败  
### 交互与视觉
- 键盘操作：通过**方向键**或**WASD**  
- 移动端通过手指滑动操作  
- 方块数值不同显示颜色也不同
- 方块合并时带有弹跳动画  
### 操作按钮  
- **NEW GAME**:开始新游戏  
- **RESTART**:重新开始游戏

## 运行方式
1. 下载项目至本地  
2. 保持index.html、index.css、game.js的相对路径不变  
3. 双击index.html即可打开浏览器开始游玩  
## 操作方法  
| 操作       | 键盘          | 移动端        |
|------------|---------------|---------------|
| 向上移动   | ↑ 或 W        | 手指向上滑动  |
| 向下移动   | ↓ 或 S        | 手指向下滑动  |
| 向左移动   | ← 或 A        | 手指向左滑动  |
| 向右移动   | → 或 D        | 手指向右滑动  |
| 开始新游戏 | 点击 NEW GAME | 点击 NEW GAME |
| 重新开始   | 点击 RESTART  | 点击 RESTART  |
